# NQueenAnswer

N-Queensパズルの解を生成・表示するC#コンソールアプリケーションです。

## 概要

N-Queensパズルは、N×Nのチェス盤上にN個のクイーンを、互いに攻撃し合わないように配置する古典的なパズルです。このプログラムは、指定されたサイズのチェス盤に対してすべての有効な解を生成し、視覚的に表示します。

## 機能

- **解の生成**: 指定されたN値に対するすべての有効なN-Queens解を生成
- **視覚的表示**: チェス盤上のクイーンの配置を■と□で表示
- **重複除去**: 回転・反転による重複解を除去した結果も表示
- **実行時間計測**: 解の生成にかかった時間を測定・表示

## 技術仕様

- **言語**: C# (.NET 6.0)
- **プロジェクト形式**: コンソールアプリケーション
- **アーキテクチャ**: オブジェクト指向設計

## プロジェクト構造

```
NQueenAnswer/
├── Program.cs                  # メインエントリーポイント
├── NQueenGenerator.cs          # N-Queens解生成ロジック
├── Chessboard.cs              # チェス盤クラス
├── Queen.cs                   # クイーンの座標クラス
├── Layout.cs                  # クイーン配置の管理クラス
├── ChessboardDebugPrinter.cs  # 結果表示クラス
└── NQueenAnswer.csproj        # プロジェクトファイル
```

## 主要クラス

### Program
- メイン処理を担当
- N値の設定（デフォルト: N=5）
- 実行時間の計測
- 結果の表示制御

### NQueenGenerator
- N-Queens解の生成アルゴリズム
- 全組み合わせの生成と有効性チェック
- 重複解の除去（回転・反転による同一解の削除）

### Chessboard
- チェス盤の状態管理
- クイーンの配置情報
- 回転・反転操作

### Queen
- チェス盤上のクイーンの座標(x, y)を表現

### Layout
- クイーンの配置パターンをシリアル化/デシリアル化
- 配置の一意性を保証

### ChessboardDebugPrinter
- 解の視覚的表示
- ■でクイーン、□で空きマスを表現

## 実行方法

### 前提条件
- .NET 6.0 SDK がインストールされていること

### ビルドと実行
```bash
# プロジェクトディレクトリに移動
cd NQueenAnswer

# ビルド
dotnet build

# 実行
dotnet run
```

## アルゴリズム

1. **全組み合わせ生成**: N^N通りの配置パターンを生成
2. **有効性チェック**: 各配置について以下をチェック
   - 同じ列にクイーンが存在しないか
   - 対角線上にクイーンが存在しないか
3. **重複除去**: 回転・反転による同一解を除去

## N値と解の個数

| N | 解の個数 | 重複除去後 |
|---|---------|-----------|
| 4 | 2       | 1         |
| 5 | 10      | 2         |
| 6 | 4       | 1         |
| 7 | 40      | 6         |
| 8 | 92      | 12        |

## カスタマイズ

N値を変更するには、`Program.cs`の以下の行を編集してください：

```csharp
const int N = 5; // お好みの値に変更
```
